# Changes in the revision candidate since submission

The candidate in `candidate/` (label G2-E) differs from the software described in the submitted manuscript. This file lists the changes made in response to the reviewers (§1), the post-submission changes the candidate inherited before those corrections (§2), and the test evidence (§3).

**These are corrections of a new candidate, not historical results.** None of them was present in the historical runner H1, in the historical M5 page H2 or in the submitted manuscript, and none is on the public website (ofty.vercel.app). The historical files in this repository are unchanged.

## 2. Post-submission changes inherited by the candidate (before October 2026 corrections)

The revision line starts from candidate C1, which already differed from the submitted modules:

- **M5:** an integrated host (`gate2/`) replaces the submitted orchestrator page. Its engine (`semantic.cjs`) compares the attested measured Goldmann IOP (not the M1 CCT-adjusted value) with the M2 target, checks the version of every module payload and blocks integration ("context_blocked") on any mismatch, and states its integrated limitation. Interface texts carry staging labels.
- **M2 target policy B-narrow-O1-0.4.1** (M2 1.1.0-gate2.1): for mild and moderate primary open-angle glaucoma (with or without baseline IOP), and for normal-tension glaucoma with confirmed progression in the stage-based mode, a thick CCT no longer raises the target range; the thick category is treated as average for the target, and the original CCT entry is kept and reported (`candidate/target-iop/index.html` l.1119 and l.1442). The ten case-specific M2 exceptions described in Multimedia Appendix 2 were not redesigned.
- **M3 2.1.0 to 2.3.0 and M4 up to 1.3.0** (M3 2.2.0 and M4 1.3.0 are also on the public website): changes listed in each module's in-page version history (for example, M3: reliability-limited series with fewer than two interpretable fields return `unclassifiable`; an `inconsistent_functional_pattern` flag in the export; exact-fit series report statistical inference as unavailable; incomplete rows block analysis).

These changes were made after submission, before the revision corrections, and were not tested by H1.

## 3. Test evidence and how to read it

- All tests used synthetic inputs and ran in headless Chromium 141 on Linux (Node.js 22, Playwright 1.56). The integrated host was run with the Windows platform hint emulated; this is **not** a Windows execution. Printing was tested as browser print-to-PDF and copying through a stub of the clipboard; no physical printing or operating-system clipboard was tested.
- The expected values are developer-specified. The tests show that the candidate returns the specified outputs for the selected inputs; they do not show clinical appropriateness.
- **Post-hoc amendments are labelled as such:**
  - **OA-E01:** the frozen G2-E evaluator v1.0 gave 35/145, because its expected export omitted the new contract version in the pre-existing copy `functional.native.transport_version`. Evaluator v1.1 adds that value and nothing else: 145/145.
  - **OA-E02:** the earlier parity check T2b gave 4/8 for the same reason and 8/8 after the same correction.
  - Both were written after the failures were observed; they were not pre-committed. The author approved them on 20 October 2026 as corrections of version-metadata expectations only. The failing outputs are kept in `evidence/`.
  - Earlier steps contain similar disclosed amendments (for example OA-01 for the M3 insufficient-series fixtures, where a text-substring check was relaxed after a failing result); they are recorded in the revision records.
- **One check fails by design:** T2c `M5_W1_in_host_unchanged` requires the M5 host page to be byte-identical to an earlier version; the page was changed in G2-E. The limitation sentence it protects is still present in every case (checked by the comparators of the 50 pressure and 28 limitation cases).
- Other batteries re-executed on the candidate: numerical table 797 pass / 94 fail with no pass-to-fail transition (the 94 concern unreachable ranges, `docs/NUMERICS.md` §4); M5 version matrix 12/12; M3 card versus export check T4 PASS.
- Reproduction: `tests/g2e_reproduction/` (public kit for the 145 evaluations). The other batteries depend on unpublished earlier candidates as comparison objects; their records are in `evidence/g2e_campaign_20261020/g2b_g2c_batteries_rerun/`.
