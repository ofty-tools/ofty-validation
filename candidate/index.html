OFTY Glaucoma Suite — revision candidate G2-E

Local navigation page for reviewers of manuscript 105677 (JMIR Formative Research)

Research prototype. Not intended or cleared for clinical use. Clinical validity and regulatory status have not been established by the tests in this repository, which use synthetic data and developer-specified expectations. Do not enter patient data.

This candidate is not the public OFTY website and is not deployed there. It is also not the software tested for the submitted manuscript (the historical test runner and its embedded M5 engine 1.0.0). The integrated M5 host still carries staging labels such as "DRAFT" and "unpublished staging build", and some exported records carry the marker REQUIRES_AUTHOR_FINAL_COPY_APPROVAL: the user-facing wording has not had final approval.

Notes for use

  • Serve this folder over HTTP on your own computer (for example python3 -m http.server 8000 --bind 127.0.0.1) and open this page from that local address. The pages were tested only when served over HTTP, not when opened directly from disk.
  • The M5 host accepts only an allow-list of browser engines (Microsoft Edge or Chromium 120 or later on Windows). On other browsers or operating systems it shows the integrated result but disables Copy, Print report and Download JSON.
  • The M1–M4 pages load web fonts from Google; this navigation page loads nothing and contains no scripts, tracking or external resources.
  • Versions, the M3→M5 export contract, the changes since submission, known limitations and the reproducible tests are described in the repository's README.md and docs/ folder.
